## 4. Drill-D6 - Entropy, XOR and codebook obfuscation

**30 minutes. Runs in the container. Data: sample payloads from the capture.**

**Objective.** Recover an obfuscated payload with entropy and XOR analysis.

**Run this.**

```bash
xxd /labs/work/samples/payload.bin | head -3
python3 -c "d=open('/labs/work/samples/payload.bin','rb').read();c=[(k,bytes(b^k for b in d)) for k in range(256) if b'beacon=' in bytes(b^k for b in d)];print(len(c), hex(c[0][0]), c[0][1][:60])"
```

**What good looks like.**

```text
1 0x5a b'beacon=45.125.66.32:2917;interval=60;jitter=25;ua=Mozilla/5.'

One candidate only, key 0x5a, and the plaintext is a config line. The learner must state why the
keyword filter is the proof, and why a plain printable test returns key 0 as a false answer.
```

**Save this evidence:** `decoded strings` in `/labs/reports/`.

**Pass criterion.** The recovered key is stated, and the proof is a readable string, not a guess.

**Common mistake.** Decoding until something looks like English, without recording the key.

## 5. Drill-D7 - Identify command and control channels

**35 minutes. Runs in the container. Data: 2025 traffic pcap.**

**Objective.** Identify command and control channels with evidence per channel.

**Run this.**

```bash
tshark -r /labs/artifacts/2025-01-22-traffic-analysis-exercise.pcap -q -z conv,tcp | head -8
tshark -r /labs/artifacts/2025-01-22-traffic-analysis-exercise.pcap -Y 'dns.qry.name contains dyngate' -c 3
```

**What good looks like.**

```text
10.1.17.215 <-> 5.252.153.241:80   5968 frames 5434 kB
10.1.17.215 <-> 45.125.66.32:2917    2881 frames 2760 kB

Two channels: HTTP with a large outbound share, and a non standard port with short requests and
long replies. Each needs a judgement on whether it is C2, staging or benign.
```

**Save this evidence:** `C2 list with evidence` in `/labs/reports/`.

**Pass criterion.** Each channel has a packet or conversation citation and a stated confidence.

**Common mistake.** Listing every external conversation as C2.

## 6. Drill-D8 - Separate exfiltration from download

**30 minutes. Runs in the container. Data: 2025 traffic pcap.**

**Objective.** Separate exfiltration from download using direction and volume.

**Run this.**

```bash
tshark -r /labs/artifacts/2025-01-22-traffic-analysis-exercise.pcap -q -z conv,tcp | head -8
tshark -r /labs/artifacts/2025-01-22-traffic-analysis-exercise.pcap -Y 'ip.src==10.1.17.215 && ip.dst==5.252.153.241' -T fields -e tcp.len | awk '{s+=$1} END {print s}'
```

**What good looks like.**

```text
10.1.17.215:50144 <-> 5.252.153.241:80   3880 frames 5304 kB out, 2088 frames 129 kB in

Outbound is 41 times the inbound volume on that conversation, which is consistent with upload,
not download. The learner must still check whether the destination is a known service.
```

**Save this evidence:** `direction and volume table` in `/labs/reports/`.

**Pass criterion.** The ratio is computed, and the learner states what would disprove exfiltration.

**Common mistake.** Assuming the bigger number means exfiltration when it is a backup or an update.

## 7. Drill-D9 - Find the successful inbound attack

**30 minutes. Runs in the container. Data: 2025 traffic pcap + evtx corpus.**

**Objective.** Find the inbound attack that succeeded, not the one that failed.

**Run this.**

```bash
tshark -r /labs/artifacts/2025-01-22-traffic-analysis-exercise.pcap -Y 'http.response.code >= 200 && http.response.code < 300' -T fields -e ip.src -e ip.dst -e http.request.uri | head -6
grep 5.252.153.241 /labs/work/logs/proxy.log | head -3
```

**What good looks like.**

```text
5.252.153.241    10.1.17.215  /api/file/get-file/264872
5.252.153.241    10.1.17.215  /api/file/get-file/29842.ps1
199.232.214.172  10.1.17.215  /filestreamingservice/files/2ed1297e-...

2025-01-22 09:02:11 10.1.17.215 CONNECT 5.252.153.241:80 200 5434000 129400

The success is the command address handing over a PowerShell script, and the proxy log dates a 5.4 MB
transfer to the same minute. The 584 failed requests from that address are the run up to it: context,
not the incident. Naming which request succeeded is the whole drill.
```

**Save this evidence:** `attack chain` in `/labs/reports/`.

**Pass criterion.** A 2xx fetch tied to the proxy transfer in the same window.

**Common mistake.** Counting the failing requests as the compromise.

## Handover brief

Two minutes at the end. Each learner answers three questions out loud, in 90 seconds:

1. **Finding.** One sentence a client would understand. No tool names.
2. **Limitation.** What this evidence cannot tell you, and why.
3. **Next step.** The single next action you would take, and who authorises it.

Record the three answers in `/labs/reports/` as the lab's closing note. This is group A4, record keeping, in practice.
