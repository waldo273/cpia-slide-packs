## 4. Drill-A2 - Timeline across three time zones

**35 minutes. Runs on kali. Data: evtx sample + plaso demo image.**

**Objective.** Reconcile timestamps from three sources into one timeline in a single time zone.

**Run this.**

```bash
plaso-log2timeline --status_view none -z UTC --storage_file /labs/work/U02.plaso /labs/artifacts/evtx
plaso-psort -q -o l2tcsv -w /labs/reports/U01-A2-timeline.csv /labs/work/U02.plaso
head -3 /labs/reports/U01-A2-timeline.csv
```

**What good looks like.**

```text
date,time,timezone,MACB,source,sourcetype,type,user,host,short,desc,...
03/19/2019,00:02:04,UTC,...B,EVT,WinEVTX,Creation Time,-,-,[4698 / 0x125a] Provider identifier: ...
03/19/2019,00:02:04,UTC,M...,EVT,WinEVTX,Content Modification Time,-,-,[4698 / 0x125a] ...

Measured on the range: log2timeline 10.1 s, psort 16.0 s, 26 s of compute for 1,066 rows.

1066 rows from one tactic folder, every row UTC, source EVT, sourcetype WinEVTX. The learner must
still say which original source was in local time and how the offset was applied.
```

**Save this evidence:** `timeline csv, zone conversions` in `/labs/reports/`.

**Pass criterion.** A single time zone column, and the offset for each source written down.

**Common mistake.** Sorting by the raw string instead of a parsed timestamp, which puts 09:00 after 10:00.

## 5. Drill-A3 - Evidence register and chain of custody

**25 minutes. Runs in the container. Data: ntfs1-gen2.E01 and ntfs1.raw.**

**Objective.** Register an exhibit, hash it, and record custody without changing the original.

**Run this.**

```bash
md5sum /labs/work/disk/ntfs1-gen2.E01 | tee /labs/reports/U01-A3-hashes.txt
ewfinfo /labs/work/disk/ntfs1-gen2.E01 | grep -iE 'media size|acquisition date' >> /labs/reports/U01-A3-hashes.txt
ls -l /labs/reports/U01-A3-custody.md
```

**What good looks like.**

```text
27a9053e35aac74608493e755353cb95  ntfs1-gen2.E01

Media size: 492 MiB (516554752 bytes)
Acquisition date: Fri Feb 22 10:54:32 2013

then a custody log with five columns: exhibit id, description, hash, acquired by, date and time.
The hash must be taken before any read only mount, and again afterwards to prove nothing changed.
```

**Save this evidence:** `custody form, hash log` in `/labs/reports/`.

**Pass criterion.** Two hashes, identical, one before and one after, plus a completed custody row.

**Common mistake.** Hashing after opening the image with a tool that writes a journal next to it.

## 6. Drill-A5 - Map the incident to ATT&CK and the kill chain

**30 minutes. Runs on kali. Data: 2025 traffic pcap + evtx corpus.**

**Objective.** Map an incident to ATT&CK techniques and one kill chain phase, with evidence per row.

**Run this.**

```bash
tshark -r /labs/artifacts/2025-01-22-traffic-analysis-exercise.pcap -q -z conv,tcp | head -8
grep -c ping3.dyngate.com /labs/work/logs/dns.log
```

**What good looks like.**

```text
The capture gives two channels (5.252.153.241:80 and 45.125.66.32:2917) and the DNS log
gives 686 queries to ping3.dyngate.com, which is the count in the fixture. Three mapped techniques
with evidence, one marked weak.
```

**Save this evidence:** `technique table, kill chain row` in `/labs/reports/`.

**Pass criterion.** Each row cites a packet, log line or file, and one row is honestly marked weak.

**Common mistake.** Listing eight techniques with no evidence, which reads as a threat report, not analysis.

## Handover brief

Two minutes at the end. Each learner answers three questions out loud, in 90 seconds:

1. **Finding.** One sentence a client would understand. No tool names.
2. **Limitation.** What this evidence cannot tell you, and why.
3. **Next step.** The single next action you would take, and who authorises it.

Record the three answers in `/labs/reports/` as the lab's closing note. This is group A4, record keeping, in practice.

## If you are ahead, or behind

- Ahead: take the last drill and redo it with the tool's limitation tested, for example run the same query a second way and reconcile the answers.
- Behind: drop the last drill and keep the evidence review. Never drop the handover brief, it is where the learning lands.
