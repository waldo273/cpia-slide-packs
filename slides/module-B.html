Topic B1 · Protocols

Understanding protocols

  • Protocols govern exchange networking protocols define how systems and devices exchange data
  • SMTP defines how email applications send email
  • FTP defines how files are transferred to a server
  • The OSI model a seven-layer reference model that frames protocol interactions
  • Protocol awareness is the foundation for reading captures and reconstructing attacks
Topic B1 · IP

The Internet Protocol (IP)

  • Routes data IP routes data from source to destination using special network addresses
  • Unique numerical identifiers assigned to all devices on the network, e.g. 192.168.10.2
  • Two standards in use IPv4 and IPv6
  • IPv4 32-bit address, about 4 billion addresses, split into four sections
  • IPv6 128-bit address, 2^128 addresses, split into eight sections

Topic B1 · IP

IPv6 addressing

  • 128-bit address vast address space — 2^128 possible addresses
  • Eight sections an IPv6 address is written as eight groups of hex digits
  • Three categories unicast, multicast and anycast
  • Zero compression consecutive zeros are represented with '::'
  • Example FE80::FFFF:C0A8:0A02 (link-local address)

Topic B1 · ICMP

Internet Control Message Protocol

  • Error reporting and diagnosis ICMP provides error-reporting and helps solve network problems
  • Used by ping echo request/reply underpins connectivity testing
  • Attacker abuse attackers use ICMP to launch Denial-of-Service (DoS) attacks
  • Smurf-style floods broadcast amplification and ping floods are ICMP-borne
  • Analyst value ICMP in captures can reveal probing, reachability and covert channels
Topic B1 · TCP

Transmission Control Protocol

  • Works alongside IP TCP sends packets to other network devices reliably
  • Three-way handshake SYN, SYN-ACK, ACK establishes a connection
  • Packets data is divided into packets for transmission
  • Checksums ensure data is not corrupted in transit
  • Sequence numbers detect loss and rebuild data in the correct order
Topic B1 · TCP/UDP

Common uses of TCP and the UDP contrast

Protocol Reliability Common uses
TCPReliable: handshake, checksums, sequencingHTTP(S) port 80/443, FTP 20/21, SMTP 25
UDPUnreliable: no error detection, no sequencingOnline gaming, media streaming, VoIP
Topic B1 · DNS

Domain Name System

  • Maps names to addresses www.cybercoaching.com = 198.185.159.145
  • Hierarchical, distributed database no single server holds all records
  • Query types DNS lookups and reverse DNS lookups
  • Used by many applications web browsers, email and utilities such as ping
  • Resolution order host file → local/internal DNS → public DNS (ISP)
Topic B1 · HTTP

Hypertext Transfer Protocol

  • Web protocol exchanges information while browsing the World Wide Web
  • Runs over TCP/IP port 80 by default
  • GET retrieve HTML documents, scripts and images
  • HEAD retrieve meta-information in the response headers
  • POST send data from web pages such as login forms
  • Response codes 401 Unauthorised, 404 File not found, 500 Internal server error
Topic B1 · Web & email

The Internet, the WWW, and email

  • Internet vs WWW the Internet is the network of networks; the WWW is the collection of hypertext documents and media
  • Browsing the browser resolves DNS, opens a TCP connection and issues HTTP requests
  • Send email SMTP (Simple Mail Transfer Protocol) on port 25
  • Retrieve email POP (Post Office Protocol) on port 110, or IMAP on port 143
  • Analyst relevance Trojan malware commonly uses HTTP(S), SMTP and DNS for command and control

Topic B2 · Architectures

Network architectures you will encounter

  • CAT 5/6 and fibre the physical layer fundamentals of every network
  • 10/100/1000baseT twisted-pair Ethernet speeds over IEEE 802.3
  • Windows domains central directory service with domain controllers
  • NAT Network Address Translation to reuse IP addresses
  • 802.11 wireless Wi-Fi standards across 2.4 GHz and 5 GHz
  • VLANs, subnets, routing segmentation and the path packets take
Topic B2 · Cabling

CAT 5/6 and Ethernet

  • CAT 5 ANSI/TIA/EIA-568-A with clarification in TSB-95; 8P8C (RJ45) connectors
  • Termination T568A or T568B wiring schemes
  • CAT 6 Gigabit Ethernet (1 Gbps), backwards compatible, faster performance
  • Reduced length CAT 6 is limited to 100 metres
  • 10/100/1000baseT 10, 100 and 1000 Mbps over twisted pair (IEEE 802.3)
Topic B2 · Fibre

Multi-modeCarries multiple wavelengths; cheaper than single-mode100 Mbps (2 km), 1 Gbps (1 km), 10 Gbps (550 m)
Topic B2 · Domains & NAT

Windows domains and NAT

  • Windows domain a central database/directory service managing a set of resources
  • Domain controllers authenticate users and enforce policy
  • NAT first defined in RFC 1631 as a short-term fix for IP address depletion
  • Address reuse only a subset of internal addresses need translation when talking outside
  • NAT architectures full cone, address-restricted cone, port-restricted cone, symmetric
Topic B2 · Wireless

802.11 wireless LANs

  • Standards 802.11 a/b/g/n across 2.4 GHz and 5 GHz (others exist)
  • New naming 802.11b=Wi-Fi 1, 802.11a=Wi-Fi 2, 802.11g=Wi-Fi 3, 802.11n=Wi-Fi 4, 802.11ac=Wi-Fi 5, 802.11ax=Wi-Fi 6
  • Shared media concerns copyright, theft, synchronisation and infection on shared media
  • VLANs data-link-layer segmentation providing security and traffic management
  • Analyst value rogue access points and weak wireless crypto are common findings
Topic B2 · Subnets & routing

IP subnets and routing

  • Subnet an identifiable separate part of a network
  • Subnet mask separates the network portion from the host portion
  • IPv4 subnets 32-bit addresses; IPv6 uses 128 bits
  • IP forwarding algorithm determines how packets are routed across interconnected networks
  • Routing protocols BGP, IS-IS, OSPF, and RIP (15 hops maximum)

Topic B4 · OS fingerprinting

Passive OS fingerprinting

  • Stealthy capture stealthily capture network packets to avoid detection
  • Gather intelligence learn more information about a target without touching it
  • Not 100% accurate the results provide a foundation rather than certainty
  • Used by attackers too the same technique feeds reconnaissance
Topic B4 · OS fingerprinting

Packet value matching

  • Match known values passive fingerprinting matches well-known values in packets
  • TTL time-to-live values differ by OS
  • Window size TCP window sizes are characteristic
  • Other fields don't-fragment flag, type of service, presence or absence of options
  • Tool databases accuracy depends entirely on the signatures stored in the tool's database
Topic B4 · p0f

The p0f OS fingerprinting tool

  • Developer Michal Zalewski
  • Platform Linux, command-line based
  • Capabilities monitors, captures and examines traffic without sending any packets to the target
  • Command p0f -i eth0 -p
  • Truly passive because it sends nothing, it stays stealthy
Topic B4 · NetworkMiner

NetworkMiner as a passive fingerprinting tool

  • Passive OS fingerprinting identifies the target operating system from observed traffic
  • Two versions an open-source version with few limitations and a professional version with additional features
  • Complement to p0f a GUI alternative for Windows-based analysis

Topic B5 · Application fingerprinting

Application fingerprinting

  • Identify applications and versions determine server types and application versions from evidential data
  • Four main methods metadata, service banners, user-agent strings, email headers
  • Client software versions identified from metadata within common document types
  • Server software versions identified from banners and headers
  • Legitimate and illegitimate the same techniques serve both defence and attack
Topic B5 · Metadata

Document metadata

  • Rich in information metadata yields extensive application information, often hidden from view
  • Word Metadata Dumper a Perl script that extracts metadata from Office documents (not the latest formats)
  • DOCX files latest Office types can simply be extracted with a compression tool
  • app.xml the docProps\app.xml file holds the application name
  • PDF pdfinfo is a portable document information extractor for Windows and Linux
Topic B5 · Banners

Banner grabbing

  • Information-gathering technique gather the application name and version number
  • Assess security risk the banner reveals how dated or vulnerable a service may be
  • Example FTP on an open port returning 'FileZilla 0.9.41 beta'
  • Server identification banners identify the application, e.g. the web server software
Topic B5 · User agents

User-agent strings and spoofing

  • Why they exist browsers advertise themselves so servers can optimise layout, e.g. mobile versus PC
  • Contains system info the user-agent string includes browser and OS details
  • Easily spoofed anyone can modify the user-agent to pretend to be another browser or device
  • Content gating spoofing can reveal content restricted to certain browsers or devices
Topic B5 · Email headers

Email headers

  • Two parts an email has a header and a body
  • Tracing the sender headers can be used to trace the location of the sender
  • Basic fields FROM, TO, DATE, SUBJECT, CC (carbon copy) and BC (blind copy)
  • Viewing headers Gmail 'Show original'; Thunderbird 'Message Source'; Outlook 'Properties'
Topic B6 · NAC

Network Access Control (NAC) analysis

  • What NAC does authenticates and authorises devices before granting network access
  • Posture assessment checks that a device meets policy (patches, antivirus, compliance)
  • Common mechanisms 802.1X port-based access control, endpoint agents, RADIUS backends
  • Analyst relevance assess whether NAC logs capture who and what connected, and any bypass
  • Evidence value NAC records tie a device identity to a time and place on the network

Topic B7 · Crypto

Encryption versus encoding

  • Both transform data encryption and encoding both change data into another format
  • Both can be reversed neither is a one-way operation by itself
  • Encoding transforms data to be used on a different system; not secret; decoding methods are public
  • Encryption data cannot be used by unauthorised users; relies on secret keys
  • Key distinction encoding is reversible without a secret; encryption requires a key
Topic B7 · Crypto

Threats and security services

  • Threats unauthorised access, disclosure and modification of information
  • More threats misrepresentation of origin, repudiation of a message, replay of a message
  • Cryptography counters threats the core mechanism against these risks
  • Security services confidentiality, authentication, integrity, non-repudiation
  • Mechanisms symmetric ciphers, hashes and MACs, asymmetric ciphers, digital signatures
Topic B7 · Symmetric

Symmetric ciphers

  • Confidentiality protection the primary purpose
  • Same key the same key value is used to encipher and to decipher
  • Security in the key assume the attacker knows the system and algorithm — secrecy relies on key protection
  • Random key generation keys should be generated randomly
  • Examples DES, 3DES, AES and RC4
Topic B7 · Asymmetric

Asymmetric ciphers

  • Key pair a single private key holder but many public key holders
  • Mathematics relies on factorisation of large primes and elliptic curves
  • Dual purpose provides both confidentiality and integrity protection
  • Substitution risk replacing the public key element requires protection
  • Speed very slow compared with symmetric cryptography
Topic B7 · Hashes

Hash functions and HMAC

  • Hashing equals integrity a hash verifies data has not changed
  • SHA Secure Hash Algorithm family
  • MD5 Message Digest algorithm, now considered weak
  • HMAC a keyed Message Authentication Code providing integrity and authentication
  • Analyst use hash files to verify evidence integrity during acquisition
Topic B7 · Signatures

Digital signatures and certificates

  • Sign and validate only one entity can sign with the private key; many may validate with the public key
  • Integrity and non-repudiation signatures provide both and counter sender denials
  • Certificates hold public keys and identity, digitally signed by a trusted authority
  • Why certificates a bare public key is trivial to forge; a certificate ties key to identity
  • Trust the signing authority is recognised and trusted by the community
Topic B7 · Key exchange

Key exchange and management

  • Symmetric key exchange manual or via PKI techniques
  • Asymmetric key exchange PKI, often with an LDAP server publishing certificates
  • PGP Pretty Good Privacy — supports signing and encrypting/decrypting
  • Hybrid use PGP uses both symmetric and asymmetric ciphers
  • Web of trust PGP's trust model, distinct from a central CA

Topic B8 · Applications

Applications of cryptography: SSL/TLS, IPSec, SSH, PGP

  • SSL/TLS encrypted link between client and server; SSL by Netscape, replaced by TLS
  • IPSec Internet Protocol Security; end-to-end scheme used in VPNs; transport and tunnel modes
  • SSH Secure Shell — securely log into another device via a network
  • PGP encrypt and decrypt email over the Internet; low-cost solution

Topic B9 · Permissions

File system permissions

  • NTFS permissions control access to files and folders: read, write, execute, full control
  • ACLs access control lists bind users and groups to allowed actions
  • Ownership and inheritance permissions inherit down the tree; ownership grants full control
  • Analyst relevance permissions reveal what an intruder could read, modify or execute
  • Shared vs NTFS effective access is the intersection of share and NTFS permissions

Topic B10 · Host analysis

Sockets, ports and processes

Assessing patch levels on a Windows host

  • DISM DISM /Online /Get-Packages lists installed packages
  • Patch gaps missing patches are a common intrusion vector

Topic B11 · Data formats

Understanding common data formats
