Topic C1 · Registration records

What are registration records?

  • Stored in the WHOIS database information about IP addresses and domain names
  • Used by registrars GoDaddy, Fasthosts and many others
  • A free resource accessible to anyone without cost
  • Reveals individuals and organisations registrant type, address and contact details
  • Looked up online whois.net, whois.com, who.is, whois.domaintools.com
Topic C1 · Registration records

Information stored in registration records

  • Registrant type whether the holder is an individual or an organisation
  • Registrant's address postal and registered address of the holder
  • Registrant's contact details telephone, email and technical contacts
  • Registrar the company through which the domain was registered
  • Registration dates created, updated and expiry
  • Name servers the authoritative DNS servers for the domain
Topic C1 · Registration records

WHOIS in the investigation

  • Valuable intelligence WHOIS can hold valuable information about a target
  • Privacy protection registrant details can be removed from the database
  • Varying depth some websites retrieve more information than others
  • Cross-check correlate WHOIS data with DNS and other open sources
  • Limits anonymised and proxy-registered domains reveal little
Topic C2 · DNS

The Domain Name System

  • A hierarchical, distributed database shared among DNS name servers
  • Forward lookups resolve a name such as www.pgittl.com to an address
  • Reverse lookups map an address back to a name
  • Widely used web browsers, email clients and utilities such as ping
  • Two-step resolution root-level servers direct to top-level, then second-level servers
Topic C2 · DNS

Structure, interpretation and analysis of DNS records

Record Purpose
AHolds the fully qualified domain name → address mapping
CNAMEAlias; multiple services via one name or address (e.g. FTP and HTTP)
NSIdentifies the authoritative name servers for the domain
SOAStart of authority — variety of information about the domain and its zone
MXSpecifies the mail server through which email should be delivered
TXTFree-form text of any type (often SPF / DKIM)
PTRMaps a network interface (IP) to a host name
HINFOInformation about the server's hardware and operating system
Topic C2 · DNS

DNS zone transfers

  • Replication transfers DNS information to another DNS server
  • Full transfer resource intensive and a lengthy process
  • Incremental transfer less resource intensive and quicker
  • Facilitates attacks transferred information can reveal the whole zone
  • Preventive measure restrict transfers to authorised DNS servers
Topic C2 · DNS

Dynamic DNS and fast-flux DNS

  • Dynamic DNS (DDNS) maps dynamic IP addresses to domain names
  • Automation DDNS providers automate the constant record updates
  • Security implications phishing and malicious sites that constantly change IP
  • Hard to shut down constantly moving targets are difficult to take offline
  • Fast-flux DNS changes IP addresses every couple of minutes
  • Cybercriminal use to hide their location and avoid detection

How search engines work

  2. Copy pages
    for the purpose of indexing

    the indexed data
  4. Garbage in, garbage out

Topic C3 · OSINT

Online intelligence sources

  • Meta-search engines aggregate results across multiple engines
  • Online directories businesses by name, location and categorisation
  • People-search websites find a person by name and location
  • Archived websites free snapshots of historical web pages
  • Interactive maps Google Maps / Earth — street view, terrain, live traffic
  • Social networking Facebook, Twitter, LinkedIn — 'post first, think second'
Topic C3 · OSINT

theHarvester

  • Gathers from public sources emails, subdomains, hosts, employee names, open ports and banners
  • Time delays between requests to stay under the radar
  • Active enumeration DNS enumeration, reverse lookups, TLD expansion
  • SHODAN integration open ports and banners from the computer database
  • Output save to XML and HTML with a basic graph and stats
  • Examples theharvester -d microsoft.com -l 500 -b google
Topic C4 · Document metadata

Extraction of document metadata

  • Hidden data documents carry metadata beyond the visible content
  • Author and organisation the name of the creator and their company
  • Dates and times created, modified and printed
  • Application and paths the software used and the machine / folder it came from
  • Embedded objects and revisions hidden sheets, tracked changes, prior text
  • Tools exiftool and similar metadata readers
  • Risk metadata leaks information the author never intended to share
Topic C5 · Community knowledge

Community knowledge and threat reports

  • Threat reports readily available — summaries of threats, key findings, concepts and forecasts
  • VirusTotal multi-engine file and URL reputation checking
  • Open-source research cheap, global, and tried and tested
  • Public wikis and open security communities
  • Free investigation tools Autopsy for disk analysis, Live View for imaging
Topic C5 · Community knowledge

Eliminating false positives

  • False dependence on commercial tools a single vendor's verdict is not proof
  • Use multiple vendors' data cross-check one engine's result against others
  • Recognise and analyse results yourself do not outsource judgement to a scanner
  • Interpret reports read the technical detail, not just the verdict
