Session objectives

By the end of this session you will be able to

  • Interpret Windows file-structure artefacts Prefetch, shadow copies, pagefile, hibernation
  • Analyse application file structures archives, browsers, PE files, Office, PDF, email
  • Work with the Windows registry its hives and the keys that reveal persistence

Topic E4 · File structure

Windows Prefetch

  • Purpose Prefetch speeds application startup by pre-loading code and data
  • Location %SYSTEMROOT%\Windows\Prefetch, with a .pf extension
  • Contents application name, location, files used, launch count
  • Timestamps time and date of the last launch
  • Forensic value reveals programs run and supports a timeline of execution
  • Anti-forensic signs can help identify potential intrusions and wiping activity
Topic E4 · File structure

User profiles and temporary files

  • User profiles files, folders, configurations and settings for a user account
  • Local vs roaming local is device-bound; roaming is copied and synced from the server
  • Locations XP uses Documents and Settings; Vista/7/8/10 use Users
  • Temporary files %SystemRoot%\Windows\Temp; names often start with ~ and end .tmp
  • Office tmp files used for editing, document recovery and printing services
Topic E4 · File structure

Restore points and volume shadow copies

  • System Restore Points backups of vital configurations and files, not user data
  • Restore location %SystemRoot%\System Volume Information
  • Volume Shadow Copies (VSS) snapshots of volumes for backing up system and user files
  • vssadmin list shadows lists shadow copies for a given volume
  • mklink /D mounts a shadow copy to a directory for access
  • ShadowExplorer browses and exports the contents of shadow copies
Topic E4 · File structure

Hosts file, pagefile and hibernation

  • Hosts file an address book linking hostnames to IP addresses; vulnerable to hijacking
  • Hosts location %SystemRoot%\System32\drivers\etc; hidden in Explorer
  • Pagefile.sys used as virtual RAM when the system is low on memory
  • Hibernation file hiberfil.sys preserves the running state without power
  • Acquisition specialist tools and data carving extract their contents
  • Volatility used to convert and analyse hibernation file contents
Topic E4 · File structure

Shimcache, recycle bin and event logs

  • Shimcache (AppCompatCache) tracks program execution; less reliable than Prefetch
  • Shimcache location HKLM\SYSTEM\CurrentControlSet\Control\SessionManager\AppCompatCache
  • Recycle Bin Vista+ stores $R and $I files under $Recycle.Bin\%SID%
  • Event logs Application, System and Security logs
  • Log locations .evt (XP) and .evtx (Vista+) in winevt\Logs
  • Useful event IDs e.g. 4624 successful logon, 4720 account created
Topic E4 · File structure

Active Directory and WMI

  • NTDS folder stores the Active Directory database and related files
  • NTDS location %SystemRoot%\Windows\ntds (2003+)
  • Common files ntds.dit, edb.log, edb.chk, res1.log, res2.log
  • Registry key HKLM\SYSTEM\CurrentControlSet\Services\NTDS\Parameters
  • WMI core Windows management; start processes, schedule tasks, query logs
  • WMIC command-line interface; wmic.exe /node:computername for remote use

Archive formats and file signatures

  • Signature analysis identifies the true file type from known header values
  • HxD editor a hex editor used to inspect raw file headers
Topic E5 · Application files

Browser artefacts

  • Forensic value visited URLs, search queries, cache, cookies, bookmarks
  • Additional data form history, downloads, saved credentials
  • Web history stores URL, title, timestamps and visit counts
  • Cache improves loading speeds; acts as temporary storage
  • Internet Evidence Finder commercial tool for live and dead browser examinations
  • Browsing History View NirSoft tool supporting multiple browsers
Topic E5 · Application files

PE files, Office documents and PDF

  • Portable Executable (PE) the Windows executable format, parsed by tools like PEDump
  • Office documents macros can be directly malicious or unpack payloads
  • File names .docx versus .docm reveal whether macros are enabled
  • PDF can carry JavaScript and embedded actions
  • PDFiD scans PDFs for suspicious keywords and JavaScript
  • Email files Exchange and PST structures analysed with libpff, libpst and viewers
Topic E6 · Registry

The Windows registry — hives and files

Hive Holds
HKLM (Local Machine)System-wide settings; contains SAM, SECURITY, SOFTWARE, SYSTEM
HKCU (Current User)Settings for the currently logged-on user
HKCR (Classes Root)File-type associations and COM registration
HKU (Users)Settings for all loaded user profiles
HKCC (Current Config)Current hardware profile configuration
Topic E6 · Registry

Registry persistence and analysis

  • On-disk hive files SYSTEM, SAM, SECURITY, SOFTWARE, DEFAULT, NTUSER.DAT
  • Startup keys Run keys and RunOnce reveal programs that launch at logon
  • Persistence hunting malware registers itself under startup keys to survive reboot
  • ProfileList HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList lists SIDs
  • Registry monitors RegMon-style tools observe live registry activity
  • Shimcache the AppCompatCache is itself a registry-stored artefact
Topic E7 · Suspect files

Identifying suspect files — hashing and strings

  • Hash tables compare file hashes against known-good and known-bad sets
  • NSRL National Software Reference Library of known unmodified software
  • HashKeeper drug-intelligence hash set of known good and bad files
  • MD5 sets user-generated and maintained hash collections
  • Strings searching for known strings and commands in scripts and files
  • Obfuscation hex-encoded strings and JavaScript unescape() hide the real text
Topic E7 · Suspect files

Packed executables, fuzzy hashing and permissions

  • Packed executables small hidden payloads that unpack at runtime
  • Identified by few imports, little automated code discovery, unusual section names and sizes
  • Fuzzy hashing rolling hashes hint at the amount of change and identify similar files
  • Disadvantages falls over with many changes; slow and computationally intensive
  • File permissions NTFS permissions — read, write, read & execute, modify, full control
Topic E8 · Storage media

The range of storage media

  • Hard drives magnetic platters; SATA, PATA/IDE and SCSI interfaces
  • Solid-state drives flash-based; wear-levelling affects data recovery
  • Removable media USB pens, memory cards, CDs and DVDs
  • RAID arrays multiple drives combined; imaging must preserve the array
  • Write blocking hardware write blockers are essential for any source drive
  • Interfaces SATA/PATA/IDE/SCSI adaptors are part of the grab pack
Topic E9 · Memory

Memory analysis with Volatility

  • Volatility the open-source memory analysis framework
  • Profiles e.g. --profile=Win7SP0x86 to match the memory dump
  • Processes list running processes and identify parent/child relationships
  • DLLs dlllist enumerates DLLs loaded into a process
  • Sockets and connections reveal rogue listeners and remote connections
  • Hidden processes dlllist with an offset can inspect hidden processes
Topic E9 · Memory

Memory artefacts worth hunting

  • Clipboard contents may hold copied passwords or file-path artefacts
  • Encryption passwords TrueCrypt passphrases can be recovered from RAM
  • Command prompt history commands from terminated shells and console buffers
  • Browser history recover malicious URLs, timestamps and response headers
  • Network connections sockets and connections point to C2 infrastructure
  • Correlation match memory artefacts with on-disk applications
