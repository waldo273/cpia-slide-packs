Topic B7 · Crypto

Encryption versus encoding

  • Both transform data encryption and encoding both change data into another format
  • Both can be reversed neither is a one-way operation by itself
  • Encoding transforms data to be used on a different system; not secret; decoding methods are public
  • Encryption data cannot be used by unauthorised users; relies on secret keys
  • Key distinction encoding is reversible without a secret; encryption requires a key
Topic B7 · Crypto

Threats and security services

  • Threats unauthorised access, disclosure and modification of information
  • More threats misrepresentation of origin, repudiation of a message, replay of a message
  • Cryptography counters threats the core mechanism against these risks
  • Security services confidentiality, authentication, integrity, non-repudiation
  • Mechanisms symmetric ciphers, hashes and MACs, asymmetric ciphers, digital signatures
Topic B7 · Symmetric

Symmetric ciphers

  • Confidentiality protection the primary purpose
  • Same key the same key value is used to encipher and to decipher
  • Security in the key assume the attacker knows the system and algorithm — secrecy relies on key protection
  • Random key generation keys should be generated randomly
  • Examples DES, 3DES, AES and RC4
Topic B7 · Asymmetric

Asymmetric ciphers

  • Key pair a single private key holder but many public key holders
  • Mathematics relies on factorisation of large primes and elliptic curves
  • Dual purpose provides both confidentiality and integrity protection
  • Substitution risk replacing the public key element requires protection
  • Speed very slow compared with symmetric cryptography
Topic B7 · Hashes

Hash functions and HMAC

  • Hashing equals integrity a hash verifies data has not changed
  • SHA Secure Hash Algorithm family
  • MD5 Message Digest algorithm, now considered weak
  • HMAC a keyed Message Authentication Code providing integrity and authentication
  • Analyst use hash files to verify evidence integrity during acquisition
Topic B7 · Signatures

Digital signatures and certificates

  • Sign and validate only one entity can sign with the private key; many may validate with the public key
  • Integrity and non-repudiation signatures provide both and counter sender denials
  • Certificates hold public keys and identity, digitally signed by a trusted authority
  • Why certificates a bare public key is trivial to forge; a certificate ties key to identity
  • Trust the signing authority is recognised and trusted by the community
Topic B7 · Key exchange

Key exchange and management

  • Symmetric key exchange manual or via PKI techniques
  • Asymmetric key exchange PKI, often with an LDAP server publishing certificates
  • PGP Pretty Good Privacy — supports signing and encrypting/decrypting
  • Hybrid use PGP uses both symmetric and asymmetric ciphers
  • Web of trust PGP's trust model, distinct from a central CA

Topic B8 · Applications

Applications of cryptography: SSL/TLS, IPSec, SSH, PGP

  • SSL/TLS encrypted link between client and server; SSL by Netscape, replaced by TLS
  • IPSec Internet Protocol Security; end-to-end scheme used in VPNs; transport and tunnel modes
  • SSH Secure Shell — securely log into another device via a network
  • PGP encrypt and decrypt email over the Internet; low-cost solution

Topic B9 · Permissions

File system permissions

  • NTFS permissions control access to files and folders: read, write, execute, full control
  • ACLs access control lists bind users and groups to allowed actions
  • Ownership and inheritance permissions inherit down the tree; ownership grants full control
  • Analyst relevance permissions reveal what an intruder could read, modify or execute
  • Shared vs NTFS effective access is the intersection of share and NTFS permissions

Topic B10 · Host analysis

Sockets, ports and processes

  • Sockets and ports an endpoint of a two-way communication link; a point of entry into a system
  • Multiple connections a system can hold many simultaneous connections
  • netstat -aon run as administrator to identify ports and their owning processes
  • tasklist lists the current processes to cross-reference against netstat output
Topic B10 · Patch levels

Assessing patch levels on a Windows host

  • Service packs and hotfixes not the whole OS receives updates
  • wmic qfe list use Windows Management Instrumentation to list hotfixes
  • Export to HTML wmic qfe list brief /format:htable > output
  • DISM DISM /Online /Get-Packages lists installed packages
  • Patch gaps missing patches are a common intrusion vector

Topic B10 · More commands

Other useful commands

  • systeminfo OS, hardware and network details
  • net file shows open files on the network
  • net session lists active network sessions to the host
  • net accounts shows account and password policy settings
  • Correlate them combine these to reconstruct host state and attacker footholds
Topic B11 · Data formats

Understanding common data formats

  • Text vs binary ASCII/Unicode text versus raw binary structures
  • Timestamps Unix epoch, Windows FILETIME and log formats need converting to reconstruct timelines
  • Magic bytes / file signatures the leading bytes of a file identify its true type
  • Encodings base64 and hex are common in malware and logs
  • Analyst use identify files and normalise timestamps across evidence sources
