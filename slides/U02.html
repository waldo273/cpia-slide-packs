Topic B1 · Protocols

Understanding protocols

  • Protocols govern exchange networking protocols define how systems and devices exchange data
  • SMTP defines how email applications send email
  • FTP defines how files are transferred to a server
  • The OSI model a seven-layer reference model that frames protocol interactions
  • Protocol awareness is the foundation for reading captures and reconstructing attacks
Topic B1 · IP

The Internet Protocol (IP)

  • Routes data IP routes data from source to destination using special network addresses
  • Unique numerical identifiers assigned to all devices on the network, e.g. 192.168.10.2
  • Two standards in use IPv4 and IPv6
  • IPv4 32-bit address, about 4 billion addresses, split into four sections
  • IPv6 128-bit address, 2^128 addresses, split into eight sections

Topic B1 · IP

IPv6 addressing

  • 128-bit address vast address space — 2^128 possible addresses
  • Eight sections an IPv6 address is written as eight groups of hex digits
  • Three categories unicast, multicast and anycast
  • Zero compression consecutive zeros are represented with '::'
  • Example FE80::FFFF:C0A8:0A02 (link-local address)

Topic B1 · ICMP

Internet Control Message Protocol

  • Error reporting and diagnosis ICMP provides error-reporting and helps solve network problems
  • Used by ping echo request/reply underpins connectivity testing
  • Attacker abuse attackers use ICMP to launch Denial-of-Service (DoS) attacks
  • Smurf-style floods broadcast amplification and ping floods are ICMP-borne
  • Analyst value ICMP in captures can reveal probing, reachability and covert channels
Topic B1 · TCP

Transmission Control Protocol

  • Works alongside IP TCP sends packets to other network devices reliably
  • Three-way handshake SYN, SYN-ACK, ACK establishes a connection
  • Packets data is divided into packets for transmission
  • Checksums ensure data is not corrupted in transit
  • Sequence numbers detect loss and rebuild data in the correct order

Topic B1 · DNS

Domain Name System

  • Maps names to addresses www.cybercoaching.com = 198.185.159.145
  • Hierarchical, distributed database no single server holds all records
  • Query types DNS lookups and reverse DNS lookups
  • Used by many applications web browsers, email and utilities such as ping
  • Resolution order host file → local/internal DNS → public DNS (ISP)
Topic B1 · HTTP

Hypertext Transfer Protocol

  • Web protocol exchanges information while browsing the World Wide Web
  • Runs over TCP/IP port 80 by default
  • GET retrieve HTML documents, scripts and images
  • HEAD retrieve meta-information in the response headers
  • POST send data from web pages such as login forms
  • Response codes 401 Unauthorised, 404 File not found, 500 Internal server error
Topic B1 · Web & email

The Internet, the WWW, and email

  • Internet vs WWW the Internet is the network of networks; the WWW is the collection of hypertext documents and media
  • Browsing the browser resolves DNS, opens a TCP connection and issues HTTP requests
  • Send email SMTP (Simple Mail Transfer Protocol) on port 25
  • Retrieve email POP (Post Office Protocol) on port 110, or IMAP on port 143
  • Analyst relevance Trojan malware commonly uses HTTP(S), SMTP and DNS for command and control

Topic B2 · Architectures

Network architectures you will encounter

  • CAT 5/6 and fibre the physical layer fundamentals of every network
  • 10/100/1000baseT twisted-pair Ethernet speeds over IEEE 802.3
  • Windows domains central directory service with domain controllers
  • NAT Network Address Translation to reuse IP addresses
  • 802.11 wireless Wi-Fi standards across 2.4 GHz and 5 GHz
  • VLANs, subnets, routing segmentation and the path packets take
Topic B2 · Cabling

CAT 5/6 and Ethernet

  • CAT 5 ANSI/TIA/EIA-568-A with clarification in TSB-95; 8P8C (RJ45) connectors
  • Termination T568A or T568B wiring schemes
  • CAT 6 Gigabit Ethernet (1 Gbps), backwards compatible, faster performance
  • Reduced length CAT 6 is limited to 100 metres
  • 10/100/1000baseT 10, 100 and 1000 Mbps over twisted pair (IEEE 802.3)

Topic B2 · Domains & NAT

Windows domains and NAT

  • Windows domain a central database/directory service managing a set of resources
  • Domain controllers authenticate users and enforce policy
  • NAT first defined in RFC 1631 as a short-term fix for IP address depletion
  • Address reuse only a subset of internal addresses need translation when talking outside
  • NAT architectures full cone, address-restricted cone, port-restricted cone, symmetric
Topic B2 · Wireless

802.11 wireless LANs

  • Standards 802.11 a/b/g/n across 2.4 GHz and 5 GHz (others exist)
  • New naming 802.11b=Wi-Fi 1, 802.11a=Wi-Fi 2, 802.11g=Wi-Fi 3, 802.11n=Wi-Fi 4, 802.11ac=Wi-Fi 5, 802.11ax=Wi-Fi 6
  • Shared media concerns copyright, theft, synchronisation and infection on shared media
  • VLANs data-link-layer segmentation providing security and traffic management
  • Analyst value rogue access points and weak wireless crypto are common findings
Topic B2 · Subnets & routing

IP subnets and routing

  • Subnet an identifiable separate part of a network
  • Subnet mask separates the network portion from the host portion
  • IPv4 subnets 32-bit addresses; IPv6 uses 128 bits
  • IP forwarding algorithm determines how packets are routed across interconnected networks
  • Routing protocols BGP, IS-IS, OSPF, and RIP (15 hops maximum)
