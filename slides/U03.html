Topic B3 · Tools

Common classes of tools

  • Network monitoring capture and inspect network traffic
  • Memory acquisition capture volatile memory for analysis
  • Forensic analysis examine artifacts and reconstruct events
  • These three categories form the foundation of any intrusion analysis or reverse engineering engagement

Topic B3 · Live collection

Autoruns, opened files and the registry

  • Autoruns shows automatic startup programs, services and drivers
  • Opened Files View lists all files currently opened on the system
  • Windows Registry acquire with FTK Imager Lite, analyse with Registry Browser
  • Persistence insight startup entries and open files reveal malware footholds
Topic B3 · Password & forensics

Password recovery and forensic analysis tools

  • Password recovery recover Windows user account passwords from the SAM and SYSTEM registry files using Ophcrack
  • Autopsy an open-source forensic analysis tool
  • The Sleuth Kit (TSK) volume and file system analysis with a plug-in framework
  • Reconstruct events these tools examine artifacts and rebuild what happened
Topic B4 · OS fingerprinting

Passive OS fingerprinting

  • Stealthy capture stealthily capture network packets to avoid detection
  • Gather intelligence learn more information about a target without touching it
  • Not 100% accurate the results provide a foundation rather than certainty
  • Used by attackers too the same technique feeds reconnaissance
Topic B4 · OS fingerprinting

Packet value matching

  • Match known values passive fingerprinting matches well-known values in packets
  • TTL time-to-live values differ by OS
  • Window size TCP window sizes are characteristic
  • Other fields don't-fragment flag, type of service, presence or absence of options
  • Tool databases accuracy depends entirely on the signatures stored in the tool's database
Topic B4 · p0f

The p0f OS fingerprinting tool

  • Developer Michal Zalewski
  • Platform Linux, command-line based
  • Capabilities monitors, captures and examines traffic without sending any packets to the target
  • Command p0f -i eth0 -p
  • Truly passive because it sends nothing, it stays stealthy
Topic B4 · NetworkMiner

NetworkMiner as a passive fingerprinting tool

  • Developer Netresec
  • Platform Windows, graphical user interface
  • Passive OS fingerprinting identifies the target operating system from observed traffic
  • Two versions an open-source version with few limitations and a professional version with additional features
  • Complement to p0f a GUI alternative for Windows-based analysis
Topic B4 · Active vs passive

Topic B5 · Application fingerprinting

Application fingerprinting

  • Identify applications and versions determine server types and application versions from evidential data
  • Four main methods metadata, service banners, user-agent strings, email headers
  • Client software versions identified from metadata within common document types
  • Server software versions identified from banners and headers
  • Legitimate and illegitimate the same techniques serve both defence and attack
Topic B5 · Metadata

Document metadata

  • Rich in information metadata yields extensive application information, often hidden from view
  • Word Metadata Dumper a Perl script that extracts metadata from Office documents (not the latest formats)
  • DOCX files latest Office types can simply be extracted with a compression tool
  • app.xml the docProps\app.xml file holds the application name
  • PDF pdfinfo is a portable document information extractor for Windows and Linux
Topic B5 · Banners

Banner grabbing

  • Information-gathering technique gather the application name and version number
  • Assess security risk the banner reveals how dated or vulnerable a service may be
  • Example FTP on an open port returning 'FileZilla 0.9.41 beta'
  • Server identification banners identify the application, e.g. the web server software
Topic B5 · User agents

User-agent strings and spoofing

  • Why they exist browsers advertise themselves so servers can optimise layout, e.g. mobile versus PC
  • Contains system info the user-agent string includes browser and OS details
  • Easily spoofed anyone can modify the user-agent to pretend to be another browser or device
  • Content gating spoofing can reveal content restricted to certain browsers or devices
Topic B5 · Email headers

Email headers

  • Two parts an email has a header and a body
  • Tracing the sender headers can be used to trace the location of the sender
  • Basic fields FROM, TO, DATE, SUBJECT, CC (carbon copy) and BC (blind copy)
  • Viewing headers Gmail 'Show original'; Thunderbird 'Message Source'; Outlook 'Properties'
Topic B6 · NAC

Network Access Control (NAC) analysis

  • What NAC does authenticates and authorises devices before granting network access
  • Posture assessment checks that a device meets policy (patches, antivirus, compliance)
  • Common mechanisms 802.1X port-based access control, endpoint agents, RADIUS backends
  • Analyst relevance assess whether NAC logs capture who and what connected, and any bypass
  • Evidence value NAC records tie a device identity to a time and place on the network
