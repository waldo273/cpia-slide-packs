LAB-07 · Beaconing, C2 and exfiltration

Objectives

By the end of this lab you can

  • 1. Recover an obfuscated payload with entropy and XOR analysis.
  • 2. Identify command and control channels with evidence per channel.
  • 3. Separate exfiltration from download using direction and volume.
  • 4. Find the inbound attack that succeeded, not the one that failed.
  • 5. Place every finding against the courseware areas this lab follows: D5 Beaconing, D6 Encryption, D7 Command and Control Channels, D8 Exfiltration of Data.
From the courseware

What the course already taught you

  • D5 Beaconing: A beacon is a repeated check-in with a regular interval and a steady payload.
  • D6 Encryption: Encryption protects content, obfuscation delays reading, and encoding changes representation.
  • D7 Command and Control Channels: Command and control channels use web traffic, DNS, cloud services and redirectors, and a good implant keeps a fallback.
  • D8 Exfiltration of Data: Exfiltration is shown by direction, volume, timing and destination, not by a single packet.
  • D9 Incoming Attacks: Incoming attacks have attempts and successes.

    Step 4 of 5: What good looks like

    1 0x5a b'beacon=45.125.66.32:2917;interval=60;jitter=25;ua=Mozilla/5.'

One candidate only, key 0x5a, and the plaintext is a config line. The learner must state why the
keyword filter is the proof, and why a plain printable test returns key 0 as a false answer.
